# NPC Index

Named NPCs of SOA, organized by village. Each significant NPC (quest giver, shopkeeper, story character) gets a page — use the [NPC page template](../dev/page-templates.md#npc-page-public).

Minor NPCs (generic guards, spawned enemies) don't need pages; they're covered by the faction entries in [Villages & Factions](../lore/villages.md#non-player-factions).
